# Empezar en la app Claude Desktop

## Una sola vez: traer el repo al PC (sin PowerShell)

1. En Claude Desktop, pestaña Code: **+ New session** (Ctrl+N).
2. **Environment**: Local. **Project folder**: una carpeta donde guardes proyectos (por ejemplo Documentos).
3. Escribe: "Clona https://github.com/CacoDf/turbo.git en esta carpeta y deja el repo en la rama turbo-2."
4. Cierra esa sesión.

## Cada sesión de trabajo

1. **+ New session** (Ctrl+N), Environment **Local**, Project folder: la carpeta `turbo`.
2. Escribe "hola" o `/turbo`. El copiloto lee `docs/PROGRESO.md` y te dice qué toca.
3. Ajusta lo que te pida con los controles junto al botón de enviar:
   - Modelo (Ctrl+Shift+I)
   - Esfuerzo (Ctrl+Shift+E)
   - Modo: Plan, Auto, etc. (Ctrl+Shift+M)
4. Para ver la app mientras Claude trabaja: botón **Browser** arriba (Ctrl+Shift+B).
5. Al terminar, el copiloto te da la lista de cierre. Cada fase es una sesión nueva.
