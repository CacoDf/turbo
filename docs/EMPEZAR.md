# Empezar en tu PC (Windows)

Una sola vez. En una terminal (PowerShell):

Si todavía no tienes el repo en el PC:

```text
git clone https://github.com/CacoDf/turbo.git
cd turbo
git checkout turbo-2
```

Si ya lo tienes:

```text
cd ruta\a\turbo
git fetch origin
git checkout turbo-2
```

Después, en esa misma carpeta:

```text
claude
```

El copiloto lee `docs/PROGRESO.md` y te dice qué hacer. Si no te saluda solo, escribe `/turbo`.
